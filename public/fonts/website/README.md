# Local website fonts

Variable WOFF2 Latin subsets, regular style, weights 400–700. Downloaded from the
official Google Fonts CSS API / fonts.gstatic.com on 2026-09-11. No visitor request
is sent to Google. Each family has its original SIL Open Font License alongside
its binary. Originals: https://github.com/google/fonts/tree/main/ofl
